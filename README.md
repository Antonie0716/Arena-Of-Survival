# Arena Of Survival

Jogo digital 2D desenvolvido em Unity e C# para um trabalho acadêmico sobre desenvolvimento de jogos com apoio de Inteligências Artificiais generativas.

## Sobre o jogo

No Arena Of Survival, o jogador controla um soldado preso dentro de uma arena.

O objetivo é derrotar os três inimigos presentes no cenário. Após eliminar todos eles, uma chave é liberada. O jogador deve coletar a chave e chegar até o portão de saída para vencer a partida.

Durante o jogo, o jogador deve sobreviver aos ataques dos inimigos e se movimentar pelo cenário, que possui muros, pedras, caixas e outros obstáculos.

## Objetivo

1. Sobreviver aos inimigos.
2. Derrotar os três inimigos da arena.
3. Coletar a chave liberada após as derrotas.
4. Chegar ao portão de saída.
5. Escapar da arena e vencer o jogo.

## Controles

- **W** — Mover para cima
- **A** — Mover para esquerda
- **S** — Mover para baixo
- **D** — Mover para direita
- **Espaço** — Atacar
- **ESC** — Pausar ou continuar o jogo

## Inteligências Artificiais utilizadas

Durante o desenvolvimento foram utilizadas:

- **Claude** — apoio na criação inicial do projeto, scripts, sprites, efeitos sonoros e sistemas do jogo, posteriormente incorporados e testados no Unity.
- **ChatGPT** — apoio na análise e revisão dos scripts, identificação de possíveis melhorias e organização da documentação.
